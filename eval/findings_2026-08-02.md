## Do not over-read the quality margin

The per-system `n` differs: 41 / 43 / 44. Four cells went UNSCORED, and **three
of the four hit `webfetch_baseline`**. A judge failure that correlates with the
system under test biases a cross-system comparison, and the leaderboard's `n`
column is the only place it shows. The `extract` − `detail` gap of 0.03 is far
inside that. Filed in `BACKLOG.md` (item 2 of the judge-wobble entry).

systems. Correct. First non-Cloudflare wall vendor in the bench corpus.

`walled-listing-recovered-via-archive` (Reuters tech archive) — **`tier=none`,
and this was a real defect, not a hard case.** A 401 mapped to
`Verdict.paywall`, which matched no archive rule (that rule required a
`gate_outcome`) and no browser floor rule (those key on `connection_error`), so
`decide_next` returned `Continue`: no rung attempted at all. Fixed in `82aa421`.

Note the case name is now slightly narrow: with a browser available the URL
recovers via `browser_robust` (the free rung correctly wins before archive) and
the legacy path redirects to `/technology/`. The case still tests the thing that
matters — a walled listing must be recovered, not reported as unfetchable.
