# Fetcher pipeline

Covers the `src/a2web/fetcher/` package (retrieval → comprehension →
sufficiency → answer → verdict), `tiers/`, `handlers/`, `domain.py`, and
`actions/` — the orchestrator that turns a URL into a `FetchContext` and the
pure decision logic layered over it.

- `src/a2web/fetcher/` — the orchestrator, a package since 2026-08-02 (`openspec/changes/decompose-fetcher-into-files`). It was one 3018-line file that had grown monotonically *through* its own v0.23 interior refactor, so the fix was a tree, not another reorganization. Five groups named for the question each answers: `src/a2web/fetcher/retrieval/` (get bytes), `src/a2web/fetcher/comprehension/` (what did we get), `src/a2web/fetcher/sufficiency/` (is this ALL of it — the question ADR-0015 exists to answer and that had no name anywhere), `src/a2web/fetcher/answer/` (what did the caller ask), `src/a2web/fetcher/verdict/` (what do we tell the caller), over `context.py` (`FetchContext`, plus the frozen `FetchInputs` / `FetchResources` pair §7.2 lifted out of it — 19 fields no pipeline node ever wrote, so what remains IS the mutable per-fetch state the name promises; 79 members to 62), `pipeline.py` (the ordered chain), `telemetry.py`. The package `__init__` re-exports every name, so `from a2web.fetcher import X` still works. **Two seams are load-bearing.** `src/a2web/fetcher/retrieval/install.py` — `install(fc, TierInstall)` is the ONLY writer of the transport half (`body`, `content_type`, `final_url`, `tier_used`, `status_code`, `pre_rendered_payload`); five paths wrote it in four orders, one omitting `status_code`. `src/a2web/fetcher/retrieval/escalate/seam.py` — `escalate(fc, rung)` is the ONLY thing that dispatches a rung, and it always calls `_comprehend` (ladder → sufficiency → re-gate) on what landed; escalators no longer call comprehension forward, which is how three paths came to run three different amounts of it (browser and paid skipped sufficiency; the post-gate archive path ran neither and re-gated anyway). Both pinned by architecture tests, plus `test_fetcher_phase_ordering.py` for the orderings that hold only by statement position. **Cross-module references to a fake-able seam go through the MODULE, not an imported name** — `from .browser import _escalate_browser` freezes the reference and silently defeats a test that fakes the rung. State flows through one `FetchContext` `dataclass(slots=True)`; verdict is a pure projection of the decision log (`fc.last_gate_outcome()`); resources are non-optional `Lazy[T]` that phases `await + try/except ResourceUnavailable`.
- `src/a2web/tiers/` — Strategy + Registry. `raw.py` (curl_cffi), `jina.py` (r.jina.ai reader), `archive.py` (Wayback CDX + archive.ph hedged via anyio task group), `browser.py` (`patchright`/`zendriver` via the shelf `any_browser` package — Camoufox is gated off, see `_manifests/browser_backends/camoufox.py`), `site_handler.py`, and the paid rungs `_paid.py` (the shared base) + `zyte.py` + `firecrawl.py`, both env-gated. `_PAID_TIER_ORDER = ("zyte", "firecrawl")` — zyte is FIRST. `TIER_ORDER = ("site_handler", "raw", "jina")`; archive + browser are in REGISTRY but **not** in TIER_ORDER — orchestrator dispatches them out-of-band (archive on playbook `RetryViaArchive`; browser on gate `suggested_tier == "browser"`). The browser cap is `playbook.BROWSER_DISPATCH_CAP = 2`, **not** 1: the two dispatches are the fast Chromium rung (`browser`) and then the robust CDP rung (`browser_robust`), a separate registered tier. **`TierResult` is a typed dataclass with named fields** (`pre_rendered: Rendered | None`, `from_archive`, `from_browser`, `js_executed`, `browser_wall_ms`, `browser_bytes`, `snapshot_age_days`, `operator_hint`, `no_match`, `skipped`, `handler_name`, `conditional_hit`, `archive_source`) — never a `tier_extras: dict[str, Any]` bag; add a typed field instead.
- `src/a2web/handlers/` — site-specific tier-0 (Handler protocol = Tier + `matches(url)`). **Nine:** `arxiv.py`, `discourse.py`, `github.py` (optional `A2WEB_GITHUB_TOKEN` raises rate limit 60→5000/hr), `habr.py`, `hn.py`, `reddit.py`, `twitter.py`, `v2ex.py`, `wikipedia.py`. Handlers populate `TierResult.pre_rendered: Rendered` (typed: `content_md`, `title`, `byline`, `headings`) so the orchestrator skips trafilatura/metadata; gate still runs. No-match URLs return `TierResult(no_match=True)` and are skipped silently. **Shared helpers** (v0.23): `handlers/_common.py` provides `empty_result(url, verdict)` (was duplicated in 9 handlers) + `map_non_ok(outcome, *, url) -> TierResult | None` for the standard `FetchVerdict → Verdict` short-circuit. Reddit's shape-aware `status_code == 403` policy stays inline (only handler that needs it). **`report_rot(handler, ...)` is the ONE emitter of `handler_schema_rot`** (2026-08-03) — until then only 3 of 9 handlers could say their parse had stopped matching the site; the other six rendered an empty-but-`ok` result. Reporting does NOT decide the verdict — the handler still chooses to fail, drop an index, or mark a section. `UNRETRIEVED_MARKER` carries the three-state vocabulary lifted from `github`: `None` = unretrieved, `[]` = retrieved-and-empty. Pinned by `tests/architecture/test_every_handler_can_report_rot.py`.
- `src/a2web/domain.py` — domain-coupled glue, 149 lines as of 2026-08-01: `compute_profile_hash`, `is_live_only`, `is_search_shaped`, `rewrite_captcha_host` (Google/Bing `/search` → DuckDuckGo HTML pre-routing), `strip_reader_prefix`. Lives at top level because the previous per-domain seam directories were nuked. **`is_search_shaped` stays here deliberately**: it gates one clause of `actions.empty.is_confirmed_empty`, so it is ADR-level policy wearing a URL predicate's clothes. **`_CAPTCHA_SEARCH_HOSTS` must not be separated from `packages/block_detector`'s `_SEARCH_CAPTCHA_MARKER`** — two halves of one Google/Bing policy that a package boundary forbids linking by import; `tests/capabilities/tier_pipeline/test_captcha_policy_halves.py` is the only thing holding them together, and the failure is directional (widening the pre-routing is harmless; narrowing it leaves the marker regex as the sole guard).
- `src/a2web/actions/` — pure deterministic decision logic (no I/O, no domain writes): `playbook.py` (`next_action_after_gate` / `next_action_after_tier`), `terminal.py` (`classify_terminal(observations, resolved_verdict) -> TerminalOutcome` — the backward-looking failure-story classifier, sibling of the forward planner; shared evidence predicates `has_hard_wall_evidence` / `has_subresource_block_evidence` / `has_empty_marker`), `empty.py` (`is_confirmed_empty(observations, url)` — the empty→`ok` promotion conjunction, decided upstream of the failure-only `classify_terminal`). Per-fetch counters in `FetchContext`: `url_rewrites`, `archive_dispatches`, `browser_dispatches`.

## Rules this pipeline owns

- Never let a later stage discard a producer's own claim (handler `kind`, `_compose_next_links`, extraction escalation, catalog labelling all failed this the same week — see `docs/findings/2026-08-06-claude-md-decomposition-history.md`). A later stage may ADD to an index, never silently replace or relabel it.
- Never declare a truncation against a number that cannot differ — read the SOURCE-stated total, or say the weaker true thing ("of what we received").
- Never let a handler report retrieved-but-walled content as `ok` — any handler running a generic extractor on retrieved HTML must call `challenge_verdict` first. Pinned by `tests/architecture/test_handler_challenge_check.py`.
- Never let a degraded sub-fetch render as absent-at-source — mark the section and emit `section_unretrieved` rather than collapsing NOT-retrieved into `[]`.
- Never let a recursive renderer walk untrusted remote input unbounded — cap depth AND a shared node budget (a branch that does not advance depth, like a deleted-comment chain, defeats a depth cap alone), then declare the truncation. Pinned by `tests/architecture/test_recursive_renderers_are_bounded.py`.
